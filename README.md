
# ms-comment

`ms-comment` — это микросервис для управления комментариями в многосервисной архитектуре. Он позволяет пользователям создавать, просматривать и управлять комментариями, связанными с постами. Этот сервис предоставляет REST API для взаимодействия с данными комментариев.

## Особенности

- Создание комментариев, связанных с постами и пользователями.
- Операции CRUD для комментариев.
- Защищённая связь с использованием аутентификации JWT.
- Интеграция с сервисами `ms-post` и `ms-user`.

## Технологии

- Java 17
- Spring Boot 2.x
- PostgreSQL
- Spring Security (аутентификация JWT)
- Maven для управления зависимостями
- Docker для контейнеризации
- Lombok для сокращения шаблонного кода

## Структура проекта

Проект разделён на следующие модули:

- `model` - Содержит основные доменные модели для комментариев, включая такие поля, как `postId` и `userId`.
- `client` - Обрабатывает коммуникацию с другими сервисами (например, с `ms-user` и `ms-post`).
- `service` - Содержит основную бизнес-логику для управления комментариями.
